== Description ==

Ovantis is a dark multipurpose WordPress Block Theme designed for creative agencies, studios, and innovative brands that value visual impact and performance. Crafted with Full Site Editing in mind, it offers a sleek and immersive layout with bold headings, fine-lined typography, and soft glowing effects that create a modern and atmospheric presence. With deep customization options, flexible block patterns, and responsive layouts, Ovantis is perfect for building portfolios, corporate sites, landing pages, or digital services websites. Designed to adapt seamlessly across devices, it empowers creators to build bold experiences with clarity and elegance. Demo: https://effethemes.com/themes/ovantis-wordpress-theme/
